# FRAME Virtual Fiscalisation Website

A modern, responsive website for FRAME, a leading provider of virtual fiscalisation solutions in Zimbabwe.

## Features

- Fully responsive design that works on all devices
- Modern and clean user interface
- Animated elements for better user engagement
- Contact form with client-side validation
- Optimized for performance and SEO
- Easy to customize and extend

## Getting Started

### Prerequisites

- A web server (Apache, Nginx, etc.)
- Modern web browser

### Installation

1. Clone or download this repository to your web server's root directory
2. Ensure all files are properly uploaded
3. Open `index.html` in your web browser

## Customization

### Logo and Branding

1. Replace the logo in the `images` folder with your own logo
2. Update the color scheme in `css/styles.css` by modifying the CSS variables at the top of the file

### Content Updates

1. Edit the HTML in `index.html` to update text content
2. Add or remove sections as needed
3. Update images in the `images` folder

### Form Submission

By default, the contact form logs submissions to the console. To set up form submission to a server:

1. Update the form action in `index.html`
2. Modify the form submission handler in `js/main.js`
3. Add server-side validation and processing
